# ashirdevelops logos

Drawn from the site: the manila folder, the desk green, the stamp crimson, and League Spartan
(outlined to shapes, so the SVGs need no font installed). Open `_preview.png` to compare them,
cropped to circles at the sizes apps show them.

The mark is `<A/>`: your initial written as an HTML tag. `<a>` is the link element, so it reads as
both a monogram and code. The brackets are a lighter weight so the "A" stays the hero.

| File | Use it for |
|---|---|
| `avatar-stamp.png` | Instagram and TikTok profile picture (1080×1080). A round case-file stamp with `<A/>`; suits the circle crop. |
| `avatar-folder.png` | Alternative profile picture: `<A/>` on the folder. The clearest at tiny sizes. |
| `avatar-folder-stamped.png` | Alternative: the folder with `<A/>` stamped on in red. |
| `avatar-stamp-code.png` | Alternative: the round stamp with a plain `</>` instead of `<A/>`. |
| `mark.svg` / `mark@2x.png` | The folder with `<A/>` on its own, transparent, for anywhere small. |
| `wordmark-on-dark.svg` / `@2x.png` | Folder plus name, for dark backgrounds (link-in-bio headers, banners). |
| `wordmark-on-light.svg` / `@2x.png` | The same, for light backgrounds. |
| `plain-a/` | The earlier versions with just an "a", in case you prefer them. |

Colours: desk `#1e2722` · manila `#d8bd88` · manila shadow `#c4a46b` · ink `#36290f` ·
crimson `#c42032` (`#a11a2a` on the stamped folder) · light text `#ece7db`.

Upload the PNG for a profile picture, not the SVG: apps only take images. All the avatars keep
the whole mark inside the circle the apps crop to.
